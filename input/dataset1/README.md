## Dataset contents

- `raw_data.csv`: Original unprocessed dataset of **`Dataset1`**. It comes from https://github.com/NWPU-903PR/SGRL-DDI.
- `ddi_edges.csv`: Formatted DDI triplets (drug1, drug2, type).
- `chemical_feat.csv`: Chemical feature of drugs.
- `enzyme_feat.csv`:  Enzyme protein feature of drugs.
- `target_feat.csv`: Target protein feature of drugs.
